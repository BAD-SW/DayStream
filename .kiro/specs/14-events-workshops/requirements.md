# Phase 14: Events & Workshops

## Status: 🔲 Not Started

## Objective
Support one-off and recurring events, workshops, seminars, challenges, and retreats.

## Dependencies
- Phase 07: Booking Engine
- Phase 06: Service Management

## Scope Summary
- Event types (workshops, seminars, challenges, retreats, classes)
- Event creation and configuration
- Recurring events (weekly classes, monthly workshops)
- Capacity management and waitlists
- Ticketing (free, paid, early bird, member pricing)
- Event registration flow
- Attendance tracking
- Check-in integration
- Event communications (confirmations, reminders, follow-ups)
- Event cancellation and refund handling
- Public event calendar/listing
- Multi-day events and retreats
- Event series (e.g., 6-week program)

### Examples (Transcend)
- Breath & Ice Workshops
- Wellness Workshops

## Key Decisions Pending
- Event vs. service distinction (shared model or separate)
- Ticketing approach (seats, general admission, tiers)
- Recurring event modification rules (single instance vs. series)
