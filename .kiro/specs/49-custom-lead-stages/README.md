## Overview

Phase 48 gives every business the same fixed lead statuses (New, Contacted, then Converted, Lost or Disqualified). This phase lets a business replace the open part of that list with its own stages, for example "Tour booked" or "Offer sent", and work its leads on a board by dragging them between stages.

It was separated from Phase 48 on 2026-10-12 so that Leads can ship with a simple model first. Nothing in Phase 48 needs to be undone to add it.

**Core Features**:
- Business-defined open stages, ordered, renamable, with a default set
- Stage board with drag and drop, alongside the list
- Stage changes as sequence triggers
- Reporting by stage: counts, time in stage, drop-off
