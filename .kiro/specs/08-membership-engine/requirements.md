# Phase 08: Membership & Subscriptions

## Status: 🔲 Not Started

## Objective
Build the membership and subscription system supporting various plan types, credits, and lifecycle management.

## Dependencies
- Phase 03: Core Platform
- Phase 10: Payment Platform (for recurring billing)

## Scope Summary
- Membership types:
  - Unlimited (unrestricted access)
  - Credit-based (X credits/month)
  - Hybrid (membership + credits)
  - Punch cards (fixed number of sessions)
  - Introductory packages (first-time offers)
- Membership lifecycle (active, paused, frozen, cancelled, expired)
- Auto-renewal via subscription billing
- Credit allocation and deduction
- Credit rollover rules
- Freeze/pause membership
- Upgrade/downgrade paths
- Family/group memberships
- Membership benefits (discounts, priority booking, exclusive services)
- Membership reporting (active, churned, renewed)
- Trial periods

## Key Decisions Pending
- Credit expiration rules
- Membership transfer policy
- Proration strategy for mid-cycle changes
