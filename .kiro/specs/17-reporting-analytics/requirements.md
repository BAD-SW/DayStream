# Phase 17: Reporting & Analytics

## Status: 🔲 Not Started

## Objective
Provide business intelligence dashboards, KPI tracking, and exportable reports.

## Dependencies
- Phase 03: Core Platform
- Multiple functional phases (data sources)

## Scope Summary
- Revenue reporting (daily, weekly, monthly, by service, by category)
- Membership metrics (active, churned, renewed, growth rate)
- Booking analytics (utilization, attendance rate, no-show rate)
- Staff productivity (revenue per staff, sessions delivered, occupancy)
- Resource utilization (room/equipment usage rates)
- Customer metrics (lifetime value, visit frequency, retention)
- Dashboard widgets (configurable per role)
- Report scheduling (automated email delivery)
- Data export (CSV, PDF, Excel)
- Custom date ranges and filtering
- Comparison periods (this month vs. last month, YoY)
- Real-time vs. aggregated metrics
- Platform-level analytics (super admin — cross-tenant)

## Key Decisions Pending
- Charting library (Recharts, Chart.js, D3, Tremor)
- Data pipeline (real-time calculations vs. scheduled aggregation)
- Data warehouse for analytics (separate from transactional DB?)
- Dashboard customization level per tenant
