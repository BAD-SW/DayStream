# Phase 19: Mobile Application

## Status: 🔲 Not Started

## Objective
Build a cross-platform mobile app for customers to book, manage memberships, and engage with the business.

## Dependencies
- Phase 03: Core Platform (API)
- Phase 07: Booking Engine
- Phase 08: Membership Engine
- Phase 04: Design System

## Scope Summary
- Authentication (email, Google, Apple)
- Customer dashboard (membership, credits, upcoming bookings, activity)
- Service browsing and booking flow
- Booking management (cancel, reschedule)
- Membership management (view, purchase, upgrade)
- Payment (secure checkout, stored cards)
- Push notifications:
  - Booking reminders
  - Membership alerts
  - Marketing notifications
- QR code for check-in
- Profile management
- Per-tenant branding (white-label)
- Offline support (cached schedule, pending actions)
- App Store and Play Store deployment

## Key Decisions Pending
- React Native + Expo (confirmed direction?)
- White-label approach (single app with tenant switching vs. separate builds)
- Offline-first strategy depth
- Push notification service (Expo, OneSignal, Firebase)
