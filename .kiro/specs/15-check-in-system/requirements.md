# Phase 15: Check-In System

## Status: 🔲 Not Started

## Objective
Enable customer check-in via multiple methods with attendance and no-show tracking.

## Dependencies
- Phase 07: Booking Engine
- Phase 08: Membership Engine (session validation)

## Scope Summary
- Check-in methods:
  - QR code (customer scans on arrival)
  - Mobile app check-in
  - Reception/staff check-in
  - Kiosk mode (self-service terminal)
- Session validation (verify active membership/credits before check-in)
- Attendance tracking and history
- No-show detection and marking
- Late arrival handling
- No-show policy enforcement (fees, restrictions)
- Walk-in booking + check-in flow
- Check-in notifications to staff
- Daily attendance reports

## Key Decisions Pending
- QR code format (per-booking vs. per-customer)
- Kiosk hardware requirements
- No-show auto-detection timing
- Walk-in availability rules
