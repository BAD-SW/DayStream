# Phase 18: Website & CMS

## Status: 🔲 Not Started

## Objective
Provide tenant-customizable web presence — branded pages, content management, and SEO tools.

## Dependencies
- Phase 04: Design System (theming)
- Phase 03: Core Platform (tenant config)

## Scope Summary
- Tenant website pages:
  - Homepage
  - Services
  - Pricing
  - Staff/Team
  - Blog
  - FAQs
  - Gallery
  - Contact
- Content management (rich text editor, media library)
- Per-tenant branding (logo, colors, fonts, imagery)
- Template system (pre-built layouts per business type)
- Custom domain support
- SEO tooling:
  - Meta tags
  - Structured data (JSON-LD)
  - Sitemap generation
  - Open Graph / social sharing
- Mobile-responsive layouts
- Integration with booking flow (CTAs → book)
- Blog/news publishing

## Key Decisions Pending
- CMS approach (headless CMS integration vs. built-in)
- Page builder complexity (block-based vs. template-only)
- Existing website integration strategy (embed vs. replace)
- Content hosting (same app vs. separate static site)
