# Phase 06: Service Management

## Status: 🔲 Not Started

## Objective
Build the dynamic service engine allowing businesses to create, configure, and publish their service offerings.

## Dependencies
- Phase 03: Core Platform
- Phase 04: Design System (for service catalog UI)

## Scope Summary
- Service CRUD (create, edit, archive, delete)
- Service categories (Recovery, Treatments, Coaching, Events, custom)
- Service configuration (name, description, images, duration, capacity)
- Staff assignment per service
- Resource/room assignment per service
- Location assignment per service
- Tax rule configuration per service
- Cancellation policy per service
- Service visibility and scheduling rules
- Public service catalog (browsable, filterable)
- Service templates (pre-built configurations for common business types)

## Key Decisions Pending
- Service schema flexibility (fixed fields vs. custom attributes)
- Image storage and optimization strategy
- Category hierarchy depth (flat vs. nested)
