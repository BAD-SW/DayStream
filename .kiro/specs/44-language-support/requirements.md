# Phase 44: Language Support - Requirements

## Overview

Provide internationalization and localization so the platform can be used in multiple languages, including user-facing text and locale-aware formatting.

## Goals

- Externalize user-facing strings for translation
- Support language selection per user and/or business
- Locale-aware formatting (dates, numbers, currency)
- A workflow for adding and maintaining translations
